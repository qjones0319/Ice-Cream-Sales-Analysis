# Ice-Cream-Sales-Analysis
Hello all! This is my second Data Analytic Project, and I decided to do the main topic about Ice Cream because it's one of my favorite desserts. For this project, I wanted to take a unique approach by using AI to create synthetic data for me. I told AI to create a synthetic dataset and make it as messy as possible to practice my skills as a future Data Analyst! I was still using MS Excel, SQL, and Power BI; however, to get more experience cleaning up data, I made sure to push myself and spent a heavy amount of time using the power query editor to make the majority amount of edits. It was a push to myself because it is a very strong tool to use. For SQL, I create a list of questions to answer by creating queries with the expected and actual output to get more experience as well. I will say, it took me a bit longer to answer some of the questions, but at the end of the day, I got the results that I was looking for! Lastly, I decided to use PowerBI to make sure I had the questions layered out on a visualization that can answer pretty much any question that one might ask. I feel really accomplished finishing another project and I enjoy it!
